# settings_window

Second vizia window (Settings) opened from a button, sharing the main window model; logs frames per window per second. Build: `CARGO_TARGET_DIR=../target ~/.cargo/bin/cargo build --release` here; run `../target/release/settings_window.exe` from this folder (log: `settings_window.log`); drive with `../../tools/uxdrive.ps1 -Title SettingsProbe -Do "click 60 25"`.
