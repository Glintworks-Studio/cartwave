# ASSETS: every non-code file in the repository, and where it came from

The repository is public, so every asset must be provably ours or carry a permissive licence.
Checked on 2026-11-25 (STABILIZE_PROMPT.md §A1). "Reproduced" means the file was regenerated
from a script or command in this repository and compared **byte for byte** with the committed file.

## Audio and music

**Presets (decided 2026-11-26).** Every preset is credited to **Jeffrey Scott Frederick** as author
and gets **its own provenance entry** here: how it was made, by whom, and when. Nothing is derived
from any third-party library, game ROM or ripped patch. Every preset has its own entry in
[`presets/PROVENANCE.md`](../presets/PROVENANCE.md) (the Presets + Browser batch). A private
reference recording or fan MIDI (VISION.md "Reference listening") is never an asset and never
enters the repository (`reference-private/` is git-ignored).

## Names

No "Ableton", "Nintendo", "Konami", "Castlevania" or game titles in the UI, presets, demo data,
code identifiers or public docs. This pass removed "Ableton" from code comments, DESIGN.md and
PRODUCT.md. Kept on purpose:

- **"2A03", "VRC6", "NES", "Famicom"** name the emulated hardware, which the product can't be
  described without (nominative use). No logo or trade dress is used.
- **`CLAUDE.md`** was replaced on 2026-11-25 (app-shell run) by the audit's proposal, which names
  no publisher and no "Ableton-style"; the reference product is named only as the workflow
  reference, as VISION.md does.
- **ENGINE.md** cites the NESdev wiki page "Namco 163 audio" as a source it checked.
- **Git history** still contains "Ableton" in older commit messages (e.g. `74dcd25`). History
  is not rewritten.
